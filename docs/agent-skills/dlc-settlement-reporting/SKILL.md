# DLC Montage: Settlement & Acceptance Reporting (Abrechnung & Abnahme)

Настоящий навык регламентирует архитектуру и бизнес-правила двухконтурной отчётности DLC Montage:
1. **Финансово-расчётный контур (Abrechnung & Auszahlung)** для руководства (шефа).
2. **Контур технической приёмки (Abnahme & Freigabe)** для строительного надзора (куратора / Bauleiter Emil).

---

## 1. Два контура отчётности (Two Reporting Circuits)

Строго разделять доступ и содержание между финансовым и надзорным контурами:

### Контур 1: Финансово-расчётный (Chef / Gesamtabrechnung)
* **Цель**: табель часов монтажников, сдельные объёмы, контроль согласования цен, контроль оплат.
* **Переменная окружения**: `GOOGLE_SHEET_ID` в `.env`.
* **Скрипты**:
  * Локальный Excel: `scripts/generate_ac_master_report.py` (сохраняет в `media/exports/` и `outputs/`).
  * Синхронизация Google Sheets: `scripts/sync_google_sheets.py`.
* **Структура**:
  * Лист 1 (`Übersicht`): группировка по календарным неделям (KW 36–KW 40+), карточка выплат ab KW 38+, статус оплаты `Zahlung` (`Bezahlt` / `Offen`).
  * Листы объектов (Standorte): Блок 1 (`Stundennachweis` — часы, интервалы, сотрудники) + Блок 2 (`Leistungsnachweis` — сдельные объёмы, расценки).

### Контур 2: Техническая приёмка (Bauleiter / Abnahme)
* **Цель**: техническая приёмка выполненных работ куратором (Эмиль) без раскрытия внутренней финансовой кухни.
* **Правило изоляции**: куратор **НИКОГДА** не должен видеть ставки рабочих, зарплатные часы или внутреннюю себестоимость.
* **Переменная окружения**: `GOOGLE_EMIL_SHEET_ID` в `.env`.
* **Скрипты**:
  * Локальный Excel: `scripts/generate_emil_abnahme_report.py`.
  * Синхронизация Google Sheets: `scripts/sync_emil_google_sheet.py`.
* **Структура**:
  * Лист 1 (`Übersicht Abnahme`): объекты последних недель (KW 39, KW 40 и далее). Колонки: `Standort`, `Adresse`, `Anlage`, `Bau-Status`, `Abnahme-Status (Emil)`, `Prüfnotiz / Mängelrüge`, `Freigabe` (`Ja`/`Nein`), `Prüfdatum`.
  * Статусы приёмки:
    * `Freigegeben` (зелёный — принято, шеф может оплачивать)
    * `Nacharbeit erforderlich` (янтарный — есть замечания / доделки)
    * `In Prüfung` (серый/голубой — в процессе проверки)
    * `Nicht abgenommen` (красный — отклонено)
  * Листы объектов: только физические объёмы (`ERBRACHTE MONTAGELEISTUNGEN`: инверторы, трассы, кабели, заземление) + блок внизу листа `ABNAHMEPROTOKOLL & MÄNGELRÜGE` с нумерованными полями для замечаний и чек-листами.

## 2. Правила расчёта материалов (Material Rules)

* **Доставка и заезд за материалом (`material-delivery`)**:
  * Оплачивается по сдельщине строго как фиксированная паушаль **50,00 €** (`unit="flat"`, `psch.`, `unit_price=50.00`).
  * Не зависит от затраченных часов или числа людей в машине.
  * Фактически затраченные часы монтажников **обязательно сохраняются** в `Stundennachweis` для внутреннего учёта рабочего времени бригады.
* **Разгрузка материала на объекте (`material-unloading`)**:
  * В сдельщине оплата **0,00 €** (`unit="hour"`, `calculation_rule="zero"`, `price_mode="zero"`).
  * Часы разгрузки также фиксируются в `Stundennachweis`.
* **Исторические записи**:
  * Все исторические записи по материалам мигрированы на `material-delivery` через миграцию `0011_migrate_material_to_delivery_flat.py`.

## 3. Защита ручных правок в Google Sheets (Two-Way Protection Rule)

При повторных запусках скриптов синхронизации или добавлении новых недель (KW 41+):
1. **Никогда не затирать ручные правки человека**:
   * Перед записью данных скрипт обязан вычитать существующие значения ячеек.
   * В финансовом отчёте сохраняются выставленные статусы `Zahlung` (`Bezahlt`/`Offen`).
   * В отчёте куратора сохраняются `Abnahme-Status`, `Prüfnotiz`, `Freigabe` и `Prüfdatum`.
2. **Только дописывание и актуализация**:
   * Новые недели добавляются новыми блоками.
   * Суммы и часы пересчитываются по формулам, сохраняя ручные пометки на месте.

## 4. Статусы готовности объектов (Site Construction Status)

* Из текущего пула AC-объектов:
  * `Huttwiler Weg 28` и `Huttwiler Weg 37` — статус **`In Bearbeitung`** (в работе, не завершены).
  * Все остальные объекты — статус **`Fertiggestellt`** (завершены).
* В отчётах для незавершённых объектов статус приёмки куратора по умолчанию выставляется в `In Prüfung`, а `Freigabe` — в `Nein`.

---

## 5. Дисциплина ценообразования (Unagreed Rates Handling)

* До момента передачи официального каталога сдельных расценок от заказчика/шефа все сдельные монтажные позиции (инверторы, трассы, протяжка кабеля) отображаются как `0,00 €` («in Abstimmung»).
* Единственная согласованная ставка — это логистика материалов (`50,00 €` паушаль).
* При получении утверждённого прайс-листа:
  1. Обновить расценки в моделях `WorkType` каталога `work_catalog`.
  2. Запустить `scripts/sync_google_sheets.py` для автоматического пересчёта всех сумм в Google Таблице шефа.

---

## 6. Регламент добавления новой недели (Next Weeks Flow)

Когда наступает новая неделя (KW 41, KW 42...):
1. Убедиться, что отчёты внесены и приняты в базе CRM (`MbgDailyReport.status == "accepted"`).
2. Запустить синхронизацию финансового отчёта:
   ```bash
   python scripts/sync_google_sheets.py
   ```
3. Запустить синхронизацию отчёта куратора:
   ```bash
   python scripts/sync_emil_google_sheet.py
   ```
4. Запустить тесты качества:
   ```bash
   python -m pytest
   ```
