# DLC Montage: feature slice

## Порядок

1. Зафиксировать пользовательский результат, владельца данных и границы функции.
2. Определить модель данных, правила состояния и права доступа.
3. Реализовать сервисный контракт и API.
4. Добавить интерфейс, который использует контракт без дублирования бизнес-правил.
5. Покрыть важные сценарии тестами и выполнить проверку качества.

## Границы

- Не начинать с большого «общего менеджера» или универсального диспетчера.
- Не затрагивать другую функцию ради удобства, если связь не задокументирована.
- При изменении общего контракта явно перечислить затронутых потребителей.
