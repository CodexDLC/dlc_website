# DLC Montage: docstrings

## Правила

- Описывать фактический контракт после чтения реализации и тестов, а не угадывать поведение по имени.
- Писать docstring’и на русском по PEP 257; для расширенных применять Google-структуру `Args:`, `Returns:`, `Raises:`.
- Документировать публичные модули, классы и функции, а также сложные границы транзакций, статусов, внешних эффектов и конкурентности.
- Не добавлять формальные docstring’и к очевидным константам и тривиальным аксессорам.
- Проход документирования не меняет поведение программы, сигнатуры и архитектуру без отдельного запроса.
