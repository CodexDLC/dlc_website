# DLC Montage: публичный сайт

## Границы и дизайн

- Публичный сайт объясняет бренд и предложение; он не превращается в операционный интерфейс CRM.
- Сначала переиспользовать брендовые токены и общие компоненты, затем добавлять страницы и локальные стили.
- Повторяемые header, footer, CTA и контентные блоки выносить в сайт-слой.
- Первый экран ясно сообщает назначение продукта и ведёт к следующему действию.
- При необходимости эмоционального контекста использовать качественные реальные или сгенерированные изображения с ясными правами применения.

## Самопроверка

Проверить доступность, адаптивность, ясность CTA и отсутствие заимствованных из CRM плотных рабочих паттернов.
