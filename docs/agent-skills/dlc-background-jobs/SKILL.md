# DLC Montage: фоновые задачи

## Правила

- Задача является тонкой оболочкой над сервисом; бизнес-логика не дублируется в worker-коде.
- Идемпотентность, статус выполнения и повторный запуск проектируются до включения автоматических повторов.
- Состояние важной работы сохраняется в доменных данных, а не только в инфраструктуре очереди.
- Повторять только временные сбои с ограничением и задержкой; не повторять бесконечно отсутствующие сущности и ошибки валидации.
- Логировать старт, успешное завершение, полезные счётчики и сбой без персональных данных и секретов.
