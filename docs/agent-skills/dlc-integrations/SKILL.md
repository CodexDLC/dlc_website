# DLC Montage: интеграции

## Правила

- Изолировать детали SDK и протоколов в адаптерах интеграций; сервисы работают с семантическими методами.
- Не коммитить реальные ключи, токены, сессии или конфигурацию окружения.
- Определять явный безопасный режим для операций, создающих внешние последствия, до их внедрения.
- Ошибки сети, лимитов и временных сбоев классифицировать отдельно от ошибок валидации и прав доступа.
- Не переключать провайдер или адаптер «молча» после ошибки; политика fallback должна быть явной.
- Тестировать интеграции через внедрённые тестовые двойники, не через скрытый runtime fake-режим.
