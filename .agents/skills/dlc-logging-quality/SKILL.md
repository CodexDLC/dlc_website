# DLC Montage: логирование

## Правила

- Сообщения логов описывают событие кратким стабильным именем, а контекст передаётся структурированными полями.
- Не включать в логи пароли, токены, ключи, полные тела запросов или иные чувствительные данные.
- Использовать уровни осмысленно: debug для деталей, info для важных границ операции, warning для восстанавливаемых аномалий, error для сбоев.
- В блоках обработки исключений сохранять контекст исключения средствами логгера.
- Сквозной идентификатор запроса или операции передавать через асинхронные обработчики и фоновые задачи, когда они появятся.
