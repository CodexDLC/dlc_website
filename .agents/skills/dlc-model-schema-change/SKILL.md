# DLC Montage: модели и схема

## До изменения

Сначала определить owning feature. Предметные модели не размещаются в `cabinet`; `system` не используется как склад feature-данных.

## Порядок

1. Добавить модель или поле в feature-владельце.
2. Создать сфокусированную миграцию.
3. Обновить admin и форму, если сущность должна управляться администратором.
4. Явно подготовить selector для чтения и service для записи.
5. Добавить тесты критичных связей, прав и изменений состояния.

## Ограничения

- Использовать консервативные defaults и не удалять/переименовывать данные без явного плана миграции.
- AC/DC обычно являются значением направления у сущности, а не отдельными одинаковыми таблицами.
- Права на объект проектировать вместе с моделью назначения на проект, а не только через отображение меню.
