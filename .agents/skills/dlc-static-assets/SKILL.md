# DLC Montage: статические ресурсы

## Разделение

- Public CSS/JS принадлежат будущему сайту.
- Cabinet CSS/JS принадлежат операционному кабинету.
- Не переносить классы или собранные assets между ними неявно.

## Правила

- Редактировать исходники, а не собранные bundle-файлы.
- Для повторяемых контролов использовать компонентный слой; стили конкретной страницы оставлять у страницы.
- При добавлении нового entry point или source root обновлять соответствующий compiler config.
- После изменения статики запускать проектную сборку assets и проверять результат.
