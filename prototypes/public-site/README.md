# Публичный сайт: образец дизайна

Самостоятельная копия статического прототипа из старого репозитория [CodexDLC/dlc_website](https://github.com/CodexDLC/dlc_website), commit `15f3ba78cd85fd0957dc052736359ece6ad8c7af`. Источник сохранён в `archive/dlc_website-original-20261010` без изменений. Лицензия исходного репозитория — MIT, см. `LICENSE`.

Назначение — просмотр и выбор дизайна будущего публичного сайта DLC Montage. Этот каталог не подключён к действующему Django-сайту или CRM. Здесь только `index.html`, статические страницы и ассеты из `src/prototype/`; backend, базы, настройки окружения и история Git не скопированы.

Для просмотра откройте корневую `index.html`. Навигация содержит ссылки на каталоги с `index.html`; для переходов между страницами удобнее обычный статический сервер с корнем в этом каталоге. Сборка и установка зависимостей не требуются.

Известные ограничения:

- Контакты, показатели проектов, экономия, названия партнёров и сертификатов — демонстрационное содержимое; перед публикацией их нужно подтвердить или заменить.
- Кнопка мобильного меню не открывает меню. Контактная форма не отправляет заявку, newsletter не связан с backend.
- Kundenportal, правовые страницы и часть служебных ссылок ведут на `#`.
- Калькулятор B2C использует демонстрационную формулу `kWh × 4.2`.
- Google Fonts и отдельные изображения Unsplash загружаются из сети; права на изображения следует проверить перед использованием на публичном сайте.

Дизайн переносится в текущие Django Templates и публичную статику отдельной задачей, с сохранением границ сайта и CRM.
